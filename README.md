# X-starter

**帮助 X 新账户快速起号。**

Chrome / Edge 扩展：接上本机 [Magpie](https://github.com/yetone/magpie)，围绕正在看的对话生成四条回复候选，逐渐学会你的语气，也帮你整理值得关注和待回关的人。

默认手动生成，选好、编辑、填入后，由你在 X 发布。扩展无需再填一遍模型厂商的 API Key。

## 能做什么

| 功能 | 用法 |
| --- | --- |
| 四种回复角度 | 默认「简短寒暄、幽默打趣、严厉批评、理性分析」，每条的名称和偏好都能修改。 |
| 结合对话 | 读取同一对话已加载的主帖、上文回复和引用帖，保留作者与顺序；可以编辑、排除或手动补充。 |
| 配置表达 | 设置全局语气、严格限制、禁用词和字数；默认使用短句、口语化表达。 |
| 学习手写语气 | 本地收集确认发布成功的手写新帖和回复，排除已知插件候选；手动总结为可编辑、可导出的 Markdown。 |
| 资料卡标黄 | 关注数比粉丝数少 20% 及以上时标为芥末黄，比例可调、可关闭。 |
| 资料卡标绿 | 已认证、关注数大于粉丝数、粉丝数大于 500，三项同时满足才标绿，可单独关闭。 |
| 时间线头像绿框 | 开启后无需悬停，后台限速读取屏幕内认证作者的资料；满足绿色规则时直接标记作者头像。 |
| 定期回关名单 | 绑定账号后，每 30 分钟检查粉丝页，包含现有粉丝，每次最多整理 5 人；你逐个点击「确认回关」。 |

## 安装

1. 启动 Magpie，在其中接入至少一个可用文字模型。已经接入过就不用重复配置。
2. 在 [Releases](https://github.com/MrCrazyK/x-starter/releases) 下载扩展安装包，解压到一个长期保留的位置。也可以下载仓库源码。
3. Chrome 打开 `chrome://extensions`，Edge 打开 `edge://extensions`，开启「开发者模式」。
4. 点击「加载已解压的扩展程序」，选择**直接包含 `manifest.json` 的文件夹**。
5. 刷新已打开的 X 标签页，在扩展菜单中固定 X-starter。

扩展本身不需要安装依赖或构建。Magpie 和浏览器需要在同一台电脑运行，默认网关地址为 `http://127.0.0.1:3425`；端口可在设置中修改。模型调用使用 Magpie 已配置的接入，仍消耗对应服务的额度。

### 从旧版更新

将新版扩展文件覆盖到**原来加载的文件夹**，在扩展管理页点「重新加载」，再刷新 X 和已打开的设置页。只刷新网页不能更新后台脚本。

旧版文件夹叫 `magpie-x-reply` 也可以继续使用，无需改目录名。保留原路径有助于保留已有设置和本地语气记忆。0.5.0 新增定时任务和 X 页面访问权限，浏览器可能要求重新启用扩展。

## 生成回复

点击帖子操作栏的「✦ 4条回复」，或点击 X 自带的回复按钮打开面板，再点「生成 4 条回复」。右下角的深色 ✦ 入口排在 Grok / Chat 上方，悬停显示「回复灵感」。

展开「用于生成的原文」「对话上下文」可核对内容；在「想表达的观点」中写下你的意思。未加载的上文需要手动补充，扩展不会把整条时间线当作对话。

候选可直接修改、复制或填入。已有草稿时先选择追加、替换或取消；连续点击不会重复执行。结果未确认时先检查编辑器，扩展不会自动再填一次。

设置中的「自动生成候选」默认关闭。勾选时显示以下提示，保存后才启用：

> 如果你用的是国产网络和国产模型，建议你不要勾选，防止不小心点进一些反动贴子，提示词出现敏感文字。

该提示只显示在设置界面，不会加入模型提示词。字数和禁用词由扩展校验；其他自然语言要求由模型遵守，发布前请核对候选内容。

## 语气记忆

只学习安装后在这台浏览器发布成功的手写帖子和回复，不扫描历史帖子。草稿、发布失败和已知插件候选（包括填入后修改的候选）不纳入学习。

在完整设置的「语气记忆」中查看、删除样本，点击「更新语气记忆」才会调用模型生成 Markdown。可以修改、保存、删除或导出总结；生成回复时只附带当前账号的总结，不附带整份手写记录。

每个 X 账号独立保存，最多 5 个账号、每个账号最近 80 条样本，单条最多 3000 字符。删除样本会清空原总结，需要重新更新。跨浏览器粘贴、重启后粘贴等场景可能无法识别外部 AI 文本，可在列表删除误收内容。

收集与参考记忆可分别关闭。卸载扩展或清除扩展数据会删除本地记忆，导出的 `.md` 只是按需保存的副本。

## 资料卡颜色

只处理鼠标悬停时的资料卡，在本地计算，不调用模型。按钮、头像和认证标记保留原样。

- **芥末黄**：`关注数 ≤ 粉丝数 × (1 − 阈值 / 100)`。默认阈值 20%，关注 3200 / 粉丝 4000 刚好触发，关注 2000 / 粉丝 4000 也触发。
- **绿色**：本人资料已认证，且 `关注数 > 粉丝数 > 500`。粉丝刚好 500、关注与粉丝相同、未认证都不触发。

优先读取完整数字提示；只有 K / M / 万 / 亿等缩写时按显示值近似判断。数字未加载或无法确认时不标记。这些颜色是你设定的数量提示，不是对账号质量或安全性的判断。

## 时间线头像绿框

在「资料与头像标记」设置中勾选 **「时间线推荐关注：头像绿框」** 并保存。此项默认关闭，开启后才访问后台资料页；和悬浮资料卡的绿色开关互不影响。

- 时间线本身通常没有关注数、粉丝数。扩展只为屏幕内已认证的发帖作者排队读取公开资料页，最多同时读取 1 位、每次开始至少间隔 20 秒、每分钟最多 3 位。
- 三项同时满足才加醒目的绿色外框：**已认证、关注数 > 粉丝数、粉丝数 > 500**。粉丝刚好 500、数量相同、未确认资料时都不标记。
- 首次出现的账号需要等资料读取完成。资料在本地缓存，有效期 24 小时，最多 500 位；同一个人在其他帖子或标签页出现时可直接复用。打开普通资料页或悬浮资料卡读到的数量也会复用。
- 只标发帖作者头像，保留原有大小、点击和悬浮操作；不会把引用帖里的其他头像当作作者。同一头像被 X 复用于别的用户、认证变化或关闭功能时会重新判断并移除旧框。
- 后台读取不滚动资料页、不点击关注、不调用模型，也不用再配置 API Key。只读取用户名、数量与认证状态，不把帖子、简介或敏感文字交给模型。临时标签页通常读完即关闭；你主动打开过的标签页会保留。
- 遇到登录、验证或访问限制暂停 30 分钟。可以先处理 X 的提示，再在设置中点「清除资料缓存并重试」；清除缓存仍保留请求间隔和限额。

悬停带绿框的头像，可查看缓存中的关注数、粉丝数与资料读取时间。

## 定期回关名单

1. 在设置勾选「定期整理回关名单」，填写要绑定的 X 用户名并保存。快捷设置中的「识别账号」可从当前已登录的 X 页面读取账号。
2. 浏览器运行且登录该账号时，每半小时在临时后台标签页读取粉丝列表；也可点「立即检查」。
3. 每次最多列出 5 位尚未回关的粉丝，**包含现有粉丝**。名单显示查看数量和检查时间；受页面加载与时间限制，可能未遍历全部粉丝，不代表全量结果。
4. 每个人都要单独点击「确认回关」。扩展会再检查登录账号、对方是否仍关注你、你是否已经关注，再执行一次关注。私密账号可能只会发出关注申请。

每半小时最多确认 5 人，间隔至少 10 秒。定时任务只整理名单；名单不会自动变成关注操作。遇到账号切换、验证或限制会暂停；处理后点「立即检查」恢复。结果不明时标记待核实，不自动重试，可点名字打开资料检查。点「忽略」后不再列入该账号的后续名单。

关闭开关并保存即可取消定时检查。浏览器关闭、电脑休眠或 X 页面无法加载时不能保证准时执行。此功能不调用 Magpie，也不需要模型。

操作间隔不保证避免账号限制，使用时仍需遵守 [X 自动化规则](https://help.x.com/en/rules-and-policies/x-automation)。

## 数据与权限

- `storage`：在扩展本地保存设置、按账号分开的手写样本、语气总结和回关名单。候选缓存保存在浏览器会话中。
- `alarms`：浏览器内每半小时唤醒一次名单检查，默认关闭。
- X / Twitter 页面权限：读取当前帖子、上下文、已登录账号、悬浮资料卡；开启头像绿框后，限速读取公开资料页；启用名单功能后读取粉丝页，并执行你逐人确认的回关。只在这些站点注入界面。
- `http://127.0.0.1/*`：连接本机 Magpie，不读取其配置文件、订阅令牌或厂商密钥。

原文、所选上下文、写作要求、语气总结通过本机 Magpie 发送给所选模型服务。手写样本只有在点击「更新语气记忆」时才发送给模型。资料卡判断、头像绿框的数量缓存与回关名单不发送给模型。没有独立云后端、分析或遥测，也不会自动发布帖子或回复。

## 常见问题

**改了文件却还是旧版？** 在扩展管理页重新加载扩展，再刷新 X；确认覆盖的是浏览器实际加载的目录。

**有面板但没有原文？** 刷新 X 后重新点击目标帖子的回复按钮或「✦ 4条回复」。无法唯一确认原帖时，扩展会要求重新选择。

**连接不上 Magpie？** 确认 Magpie 正在运行，端口一致，并检查其本机访问权限和模型状态。扩展不会修改网关的安全设置。

**没有收集到手写样本？** 需要识别到当前账号及发布成功的本人新帖；刷新中断、失败、长文章编辑器或无法确认来源的内容可能跳过。

**名单为空或暂停？** 检查绑定用户名、登录账号和 X 的页面提示。列表按页面实际加载内容整理，未加载的粉丝可能需要之后再次检查。

X 页面结构会变化。若无法识别内容或操作结果，扩展会停止对应操作并提示；可附上复现步骤提交 Issue，请勿包含私人草稿、语气样本或凭据。

## 开发与验证

扩展为原生 JavaScript + Manifest V3，无运行时依赖。源码根目录可直接加载。

```sh
npm test
npm run package
```

单元测试覆盖提示词和硬限制、候选解析、账号隔离、记忆、资料卡规则，以及回关名单的逐人确认、限额、间隔、暂停和未知结果处理。打包命令会检查脚本语法和资源引用，将可直接加载的扩展输出到 `dist/`，不包含测试、浏览器数据或开发依赖。

可选的浏览器测试使用 Playwright 和独立测试浏览器环境，X 页面和模型响应均为模拟内容，不操作真实账号：

```sh
npm install
npm run test:browser
```

默认使用本机 Microsoft Edge，可设置 `BROWSER_CHANNEL=chrome` 改用 Chrome。测试输出保存在忽略提交的 `.test-output/` 下。测试通过不代表在所有 X 页面或真实账号场景完成验收。

| 文件 | 职责 |
| --- | --- |
| `shared.js` / `background.js` | 设置、提示词、模型调用、缓存与消息权限 |
| `content.js` / `context.js` / `editor.js` | 回复面板、对话提取、一次填入 |
| `learning.js` / `memory.js` | 手写发布识别、账号独立的语气记忆 |
| `profile.js` | 悬浮资料卡黄 / 绿标记 |
| `priority*.js` | 公开数量缓存、限速后台读取、时间线头像绿框 |
| `followback*.js` / `followers.js` | 定时整理、逐人确认及页面状态核验 |
| `popup.html` / `popup.js` / `popup.css` | 快捷设置、提示词、记忆与回关名单 |

为兼容旧版存储与网关记录，内部 `Magpie*` 命名、DOM 标识及本机应用标识 `magpie-x-reply` 保留。这是应用名称，不是厂商密钥。
